# Документация

Этот каталог — более подробный разбор, чем краткий статус в
[`CLAUDE.md`](../CLAUDE.md) в корне репозитория.

- [`flows.md`](flows.md) — **начать отсюда**, если нужно понять «что
  происходит, когда» — пошаговые сценарии (жизненный цикл комнаты, кик,
  реконнект, кто что видит) от первого лица каждого участника.
- [`shared.md`](shared.md) — `packages/shared`: доменные типы, контракт
  socket-событий.
- [`backend.md`](backend.md) — `apps/server`: две игровые машины (старая
  buzz-FSM, мёртвая, и новая free-text, живая), auth, S3-хранилище,
  треки/плейлисты, Socket.IO-комнаты.
- [`frontend.md`](frontend.md) — `apps/web`: роутинг (кто на каком пути),
  четыре экрана, известные ограничения.
- [`plan.md`](plan.md) — что сделано, что дальше, в каком порядке.

Порядок чтения для нового человека в проекте: `CLAUDE.md` → `flows.md` →
`shared.md` → `backend.md` → `frontend.md` → `plan.md`.
